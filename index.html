DICOM VIEWER GUIDE

Free online DICOM parser and web viewer

DICOM Parser Online is a browser-based DICOM web viewer for reading local medical imaging files. You can open a `.dcm` file, inspect DICOM metadata, search DICOM tags, and preview uncompressed grayscale images without uploading patient data to a server.

What is a DICOM parser?

A DICOM parser reads the structure of a DICOM file and extracts tag information such as Patient Name, Patient ID, Modality, Study Date, Series Description, Pixel Spacing, Rows, Columns, Bits Allocated, Transfer Syntax UID, and Pixel Data.

DICOM tag viewer

The tag table shows the tag key, tag name, VR, length, and value. You can search by tag number like `(0010,0010)`, tag name like Patient Name, modality values like CT or MR, or private creator names such as GE private tags.

Private DICOM tags

Many scanner vendors store extra information in private tags. This tool labels private creator blocks where possible, so GE, MR, image acquisition, and scanner-specific tags are easier to identify during technical review.

Local privacy-first viewer

The DICOM file is processed locally in your browser. The app is designed for technical metadata inspection and does not require file upload, login, server storage, or cloud processing.

DICOM parser FAQ

Can this web app open DICOM files?

Yes. Select or drag a `.dcm` file into the app. It parses common DICOM Part 10 metadata and displays tags in a searchable table.

Can it preview DICOM images?

It can preview uncompressed grayscale DICOM images. Compressed transfer syntaxes such as JPEG, JPEG-LS, JPEG2000, and RLE need decoder libraries before image preview can be supported.

Is this a diagnostic medical viewer?

No. This is a technical DICOM metadata parser and lightweight image preview tool. It is not intended for clinical diagnosis or medical decision-making.

Which DICOM metadata can I inspect?

You can inspect patient, study, series, image, acquisition, pixel, transfer syntax, and private tag metadata when those tags are present in the file.
